# AI Gateway Audit — 2026-04-29

> Archive snapshot: this document records the audit state on 2026-04-29 and may be stale. Verify current code, schema, and migrations before using it as implementation guidance.

## Critical: provider header auth bypass

Status: fixed.

- Admin provider create/update sanitizes `default_headers_json` and rejects auth-like headers: `Authorization`, `Proxy-Authorization`, `x-api-key`, `x-goog-api-key`, `api-key`, `apikey`, and `x-auth-token`.
- Runtime request header assembly writes `Authorization: Bearer <decrypted-key>` after default headers and provider-specific OpenRouter headers.
- Regression coverage verifies both admin sanitization and legacy stored `Authorization` override resistance.

## High: DB-driven runtime gateway config

Status: fixed.

- Gateway enable/info callers use async runtime config backed by database assignments.
- Runtime lane loads are wrapped in a transaction for a consistent assignment/model/provider snapshot.
- Circuit breaker reset is protected by internal API key middleware.
- genfity-gateway docs now document only supported OpenAI-compatible lanes and explicitly exclude rerank.

## Medium: provider health and admin operations

Status: fixed.

- Notification internal event auth uses timing-safe comparison.
- Admin provider/model update services and `PUT` endpoints are available.
- Provider key decrypt failures mark attempts as broken and report health failures when skipped.
- Provider probe locking uses `ai_provider_health.probe_in_flight_until` with `FOR UPDATE SKIP LOCKED` and a 60s probe window.
- `ai_provider_endpoints` is removed; endpoint overrides live on `ai_models.endpoint_path`.
- Wallet ledger entry types are guarded by an idempotent check-constraint migration when legacy data is clean.

## Low: gateway cleanup

Status: fixed.

- Provider preferences are built by the generic `buildProviderPreferences` helper.
- Sentinel `notIn: ['__none__']` filtering was removed.
- Provider-health raw SQL uses parameterized Prisma calls and known Prisma error handling for missing schema/table states.
- Runtime config cache invalidation clears matching gateway circuit breakers.
- Gateway metrics use the actual runtime attempt provider label.
